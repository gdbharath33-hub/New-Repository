📋 Setup Guide

To enable real AI responses:

  1. Choose your AI provider above
  2. Get an API key from the provider's website
  3. Paste the key in the API Key field
  4. Click "Save API Settings"
  5. Click "Test Connection" to verify

Environment Variables (for deployment):

VIDYARA_AI_PROVIDER=openai
VIDYARA_AI_API_KEY=sk-your-key-here
VIDYARA_OCR_PROVIDER=tesseract
